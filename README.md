# 🔗 MyLinkedIn – Full Stack LinkedIn Clone

A full-stack LinkedIn clone built using the **MERN stack** with **Next.js**, featuring authentication, social interactions, and professional networking functionalities.

---

## 🚀 Features

### 🔐 Authentication
- JWT-based secure authentication
- Login & Signup functionality
- Protected routes for authenticated users

### 📰 Posts & Interactions
- Create and view posts
- Like and comment on posts
- View other users’ profiles
- Download user profiles

### 🤝 Connections
- Send connection requests
- Accept or reject requests
- Accepted connections appear in **My Network**

### 👤 Profile Management
- Edit profile details:
  - Profile picture
  - Bio
  - Skills
  - Location
  - Education
  - Work experience

---

## 🛠️ Tech Stack

**Frontend**
- Next.js

**Backend**
